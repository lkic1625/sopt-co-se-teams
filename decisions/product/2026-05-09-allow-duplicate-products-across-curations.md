# 큐레이션 목적이 다르면 같은 상품 중복 노출 허용

- **일시**: 2026-05-09
- **상태**: 확정
- **결정자**: @
- **분류**: product
- **영향 범위**: Main, Product Card

## 문제 (Problem)

같은 상품이 여러 큐레이션 블록에 노출될 때, 중복을 허용할지 제거할지 결정해야 한다.

## 맥락 (Context)

- Main View에는 여러 개의 큐레이션 블록이 존재
- 각 블록은 다른 목적과 설명을 가짐
- 예를 들어 "봄맞이 아우터" 블록과 "데일리 코디" 블록에 같은 자켓이 포함될 수 있음
- 중복 제거는 구현 복잡도가 증가하고, 각 블록의 독립성이 약화됨

## 결정 (Decision)

**큐레이션 목적이 다르면 같은 상품의 중복 노출을 허용한다.**

- 각 큐레이션 블록은 독립적인 콘텐츠 단위로 본다.
- 같은 상품이라도 다른 큐레이션 맥락에서는 서로 다른 의미를 가진다.
- 중복 제거 로직은 구현하지 않는다.

## 이유 (Rationale)

- 각 큐레이션 블록의 스토리텔링 독립성 유지
- 중복 제거 로직은 불필요한 복잡도만 증가
- 사용자는 블록 단위로 콘텐츠를 소비하며, 전체 목록에서 중복을 인지하지 않을 가능성이 높음

## 영향 (Impact)

- **사용자 경험**: 블록 단위로는 자연스러운 노출, 스크롤 시 같은 상품을 다시 볼 수 있음
- **개발 범위**: 중복 제거 로직, 전역 상품 상태 관리 불필요
- **데이터**: 각 블록이 독립적인 상품 리스트를 가짐

## 대안 (Alternatives)

- **중복 제거**: 화면 전체에서 같은 상품은 한 번만 노출하나, 블록 간 연관성이 약해지고 구현 복잡
- **중복 시 다른 상품 대체**: 대체 상품을 찾아야 하며, 큐레이션 의도가 희석될 수 있음
