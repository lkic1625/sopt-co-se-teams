# Main 배너 캐러셀은 5초 자동 전환을 기본 동작으로 구현

- **일시**: 2026-05-09
- **상태**: 확정
- **결정자**: @기획 / @FE 합의
- **분류**: product
- **영향 범위**: Main, FE, Hero Banner, Carousel

## 문제 (Problem)

Main 배너 캐러셀의 자동 전환, 일시정지 버튼, hover 중지 등 인터랙션 범위를 어디까지 구현할지 결정해야 한다. 캐러셀 인터랙션을 모두 정교하게 구현하면 개발과 QA 범위가 커진다.

## 맥락 (Context)

Main 배너 캐러셀은 사용자가 첫 화면에서 주요 콘텐츠를 빠르게 인지하게 하는 영역이다. 현재 우선순위는 배너 콘텐츠 노출과 기본 자동 전환이며, 일시정지 버튼의 정교한 동작이나 hover 중지 경험은 핵심 구현 범위보다 낮은 우선순위다.

## 결정 (Decision)

Main 배너 캐러셀은 기본적으로 5초마다 다음 배너로 자동 전환되도록 구현한다.

일시정지 버튼은 우선 UI 요소로 만든다. 실제 일시정지 동작과 hover 시 자동 전환 중지 경험은 시간이 남을 경우 구현하는 선택 과제로 둔다.

## 이유 (Rationale)

5초 자동 전환만으로도 Main 배너의 기본 탐색 경험은 제공할 수 있다. 반면 일시정지 상태 관리, hover 중지, focus 상태, 재생 재개, 접근성 상태 표기까지 모두 구현하면 캐러셀의 복잡도가 커지고 QA 항목도 늘어난다. MVP에서는 자동 전환을 안정적으로 구현하고, 추가 인터랙션은 여력에 따라 보강하는 것이 적절하다.

## 영향 (Impact)

FE는 캐러셀이 5초 간격으로 다음 배너로 넘어가는지 우선 검증한다. 일시정지 버튼이 존재하더라도 실제 정지 기능이 구현되지 않을 수 있으므로, QA와 기획 확인 시 해당 동작은 선택 과제로 구분한다.

시간이 허용되면 hover 중 자동 전환 중지, 버튼 클릭 시 일시정지/재생 토글, 접근성 라벨 보강을 추가할 수 있다.

## 대안 (Alternatives)

- 자동 전환 없이 수동 캐러셀만 구현
- 일시정지 버튼과 hover 중지를 필수 범위로 구현
- 캐러셀 대신 고정 Hero Banner 하나만 노출
