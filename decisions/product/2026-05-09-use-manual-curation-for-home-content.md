# 홈 콘텐츠는 고정 dummy data와 수동 큐레이션으로 구성

- **일시**: 2026-05-09
- **상태**: 확정
- **결정자**: @기획 / @디자인 / @개발 합의
- **분류**: product
- **영향 범위**: Main, Data, CurationBlock, Product Card

## 문제 (Problem)

Main 홈 콘텐츠를 운영 데이터, 자동 추천, 스타일 키워드 기반 로직으로 구성하면 데이터 모델과 추천 기준을 먼저 확정해야 한다. 현재 단계에서는 리디자인 화면의 구조와 큐레이션 경험을 안정적으로 구현하는 것이 우선이다.

## 맥락 (Context)

Main 홈은 콘텐츠 블록, 대표 이미지, 상품 카드가 함께 하나의 큐레이션 맥락을 만드는 화면이다. 이번 구현에서는 운영 도구나 실제 추천 모델보다 기획자가 구성한 화면 의도를 정확히 재현하는 것이 중요하다.

## 결정 (Decision)

Main 홈 콘텐츠 블록은 고정 dummy data를 기반으로 구성한다.

대표 콘텐츠 이미지와 상품 카드는 자동 추천이나 이미지 기반 매칭이 아니라, 기획자가 구성한 수동 큐레이션 기준으로 연결한다. 같은 상품이 여러 큐레이션 블록에 중복 노출되는 것은 허용한다. 단, 각 큐레이션의 목적과 설명이 다르면 서로 다른 맥락의 노출로 본다.

priority 기반 정렬 알고리즘은 필수 구현 범위가 아니며 선택 사항으로 둔다. 스타일 키워드는 의미가 명확하지 않으므로 추가 정의 전까지 핵심 로직에 사용하지 않는다.

## 이유 (Rationale)

고정 dummy data와 수동 큐레이션은 리디자인 시안의 의도를 가장 직접적으로 반영한다. 자동 추천이나 운영 데이터 기반 노출은 모델링과 QA 범위를 크게 늘리지만, 이번 구현의 핵심인 Main 홈의 정보 구조 검증에는 필수적이지 않다.

## 영향 (Impact)

Main 홈 데이터는 예측 가능한 고정 데이터로 QA할 수 있다. 상품 중복 노출은 오류로 보지 않고, 큐레이션 목적이 다른 경우 허용된 표현으로 본다. 스타일 키워드는 추가 정의 전까지 필터링, 정렬, 자동 분류의 핵심 조건으로 사용하지 않는다.

## 대안 (Alternatives)

- 운영 데이터 기반 동적 노출
- 자동 추천 기반 상품 매칭
- 상품 중복 노출 금지
- 스타일 키워드 기반 자동 분류
