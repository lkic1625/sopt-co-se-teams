# 대표 이미지와 상품 카드는 수동 큐레이션으로 연결

- **일시**: 2026-05-09
- **상태**: 확정
- **결정자**: @
- **분류**: product
- **영향 범위**: Main, CurationBlock

## 문제 (Problem)

Main View의 큐레이션 블록에서 대표 이미지와 상품 카드를 어떤 기준으로 연결할지 결정해야 한다. 자동 연결은 알고리즘이 필요하고, 수동 연결은 기획자의 개입이 필요하다.

## 맥락 (Context)

- 각 큐레이션 블록은 대표 이미지(Hero Image)와 관련 상품 카드들로 구성
- 대표 이미지는 큐레이션의 감도와 맥락을 전달
- 상품 카드는 실제 구매 가능한 정보를 전달
- 두 요소가 같은 큐레이션 목적 안에서 연결되어야 사용자가 맥락을 이해

## 결정 (Decision)

**대표 이미지와 상품 카드는 기획자가 정리한 수동 큐레이션 기준으로 연결한다.**

- 각 큐레이션 블록의 대표 이미지와 상품 카드 목록은 기획 문서에 명시
- 코드에서는 해당 매핑을 JSON 또는 상수로 하드코딩
- 자동 추천 알고리즘은 사용하지 않는다.

## 이유 (Rationale)

- 수동 큐레이션이 29CM의 감도 높은 콘텐츠 커머스 특성에 부합
- 자동 연결은 추천 알고리즘 개발이 필요하며, MVP에서는 과함
- 기획자의 의도가 명확히 반영되어 사용자 경험의 일관성 확보

## 영향 (Impact)

- **사용자 경험**: 대표 이미지와 상품 간의 연결 맥락이 명확해짐
- **기획 업무**: 기획자가 큐레이션 매핑 문서를 작성해야 함
- **개발 범위**: 추천 알고리즘, 자동 매핑 로직 제거
- **데이터**: 큐레이션 블록 단위로 이미지-상품 매핑 테이블 필요 없음

## 대안 (Alternatives)

- **카테고리 기반 자동 연결**: 같은 카테고리 상품을 자동으로 묶으나, 감도와 맥락이 맞지 않을 수 있음
- **판매량 기반 자동 연결**: 인기 상품을 노출하나, 큐레이션의 스토리텔링 약화
